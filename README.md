# AI‑GUIDE: Fairy Tale Map — A Journey Through Kazakhstan’s Legendary World
**AI‑ГИД: Ертегілер картасы – Қазақстанның аңыз әлеміне саяхат**

Автор: Мукашева Толкынай Махатовна, учитель английского языка, педагог‑эксперт, Шұбарши жалпы орта білім беретін мектебі.

## Что внутри
- **3D‑карта Казахстана** в ярком low‑poly стиле: зелёные холмы, горы со снежными вершинами (Алтай, Тянь‑Шань, Жетысу), реки, озёра, деревья, цветы, юрты, города. 20 «волшебных книг» с фото и маленьким 3D‑героем рядом.
- **AI‑гид**: конь **Тулпар** (скакать) и беркут (летать). Управление: W A S D / стрелки, Shift — галоп, Space / C — вверх / вниз, E — войти. На телефоне — экранные кнопки.
- **Портал в 3D‑мир** каждой сказки: ворота с орнаментом, сырмак, 3D‑герои в национальной одежде (поворачиваются к вам, машут, «говорят»), музей с куполом (реальные фото + 3D‑предметы: сәукеле, қылыш, қалқан, садақ, домбыра, қобыз, шапан, сандық и др.), кинотеатр с буктрейлером, почтовый ящик с письмом, камни‑задания 1‑2‑3, памятник сказки, пчёлы, бабочки, табуны, беркуты.
- **Озвучка нейроголосами**: гид — женский голос (английский — Ava, казахский — Айгүл); герои‑мужчины — мужскими голосами, героини — женскими; буктрейлеры — мужской голос диктора. Истории можно слушать на английском и на казахском.
- **Вкладки**: каждый раздел — отдельная страница (Главная, Карта, Сказки, Машина времени, Музей, Ценности, Адал азамат, Пед. идея, Автор).
- **Титульная страница**: 3D‑книга в стиле дополненной реальности «Kazakh Fairy Tales & Legends / Қазақ ертегілері мен аңыздары» — сама открывается, из страниц вырастают юрта, Бәйтерек, герои, конь и беркут; карточка автора с фото.
- **Карта** открывается с высоты — камера спускается сквозь облака. Беркут летит только пока нажата W/▲, иначе парит на месте.
- **3D‑книга внутри мира**: все данные (история, герои, музей, трейлер, письма, задания, AI‑гид) открываются на весь экран в книге с обложкой, перелистыванием страниц и закладками‑ленточками; на правой странице 3D‑сцена «поп‑ап» (герои, предметы музея, конь).
- **Машина времени**: у каждого мира свой век, сезон и погода (снег, дождь с радугой, гроза, туман, ночь с костром и звёздами, закат, рассвет, осень, весна). Отдельная вкладка с лентой времени от древних мифов до 2002 года. Данные — `ERA` в `js/extra.js`.
- **Спокойная музыка** (мягкие аккорды и колокольчики, без «тын‑тын»).
- Вкладки, письма, 3 задания, AI‑гид, игры «Адал азамат», раздел «Педагогическая идея», «Об авторе» — на двух языках.

## Как открыть
Теперь сайт работает и **двойным щелчком по `index.html`** (3D, фото и звук встроены). Нужен интернет только для библиотеки 3D (three.js) и шрифтов.

**В интернете (GitHub Pages):** загрузите все файлы папки (кроме `_debug.html` и папки `tools/` — она не нужна на сайте), затем Settings → Pages → Branch `main` → Save.

## Как редактировать
| Что | Файл |
|---|---|
| Сказки, письма, буктрейлеры, вопросы, задания | `js/data.js` |
| Казахские тексты историй для аудиогида | `js/data-kk.js` |
| Предметы музея, списки фото, фразы гида | `js/extra.js` |
| Тексты интерфейса, педагогическая идея, автор | `js/i18n.js` |
| Фото автора | `assets/img/author.jpg` |
| Реальные фото | `assets/img/w/*.jpg` (+ `credits.json`) |

**После изменения текстов** обновите озвучку:
1. Откройте `tools/audiolist.html` в Chrome, скопируйте JSON после `CLIPS:` в `tools/clips.json` (или попросите Claude).
2. `python3 tools/make_audio.py tools/clips.json` (нужны `pip install edge-tts` и `ffmpeg`).

Вся озвучка — один женский голос без акцента: английский `en-US-AvaNeural`, казахский `kk-KZ-AigulNeural` (1064 записи). Гид сам читает каждую страницу 3D‑книги, говорит год в машине времени и при первом открытии карты спрашивает язык на двух языках. Фразы гида для книги — `SAY` в `js/extra.js`. Включить/выключить озвучку: кнопка 🔊 вверху, в мире и в книге.

**После добавления фото** в `assets/img/w/` выполните `python3 tools/make_imgdata.py`.
